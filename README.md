# LifeLink

So something I've always been worried about given I have many friends overseas,
is that when I die all of them will simply think I've abandoned them or something
in that nature. So I wanted to create an app that ensures that when I die people
that I love but never really see, will know I'm gone and subsequnetly be told
any last words I may wish for them to hear. As I thought about this I realised 
this app could help more people and I want to try and make it :3.

With that said LifeLink can be best described as a personal care and wellbeing 
application designed to help people stay connected with those who matter most.
The application aims to support people who live independently, experience
social isolation, or require assistance managing everyday responsibilities.

## Core Features

- Scheduled wellbeing check-ins
- Medication and appointment reminders
- Trusted contacts and emergency notifications
- Secure storage of important personal information
- Configurable escalation when check-ins are missed

## Technology Stack

LifeLink is intended to be developed using:

- React Native
- Expo
- TypeScript
- Supabase
- PostgreSQL

## Development Status

LifeLink is currently in early development.

The initial version will focus on user authentication, daily check-ins,
reminders, and trusted-contact management.

## Safety

LifeLink is not a substitute for emergency services or professional
medical care.

Missing a check-in does not indicate that someone has died. The application
will use configurable notification procedures and require appropriate
human confirmation for death-related notifications.
